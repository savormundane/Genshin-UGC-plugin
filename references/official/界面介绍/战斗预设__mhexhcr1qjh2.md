# 战斗预设

# 一、编辑模块切换

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/37499681-b34a-4beb-b99e-9731dcd4eed7.png)

通过左侧边栏可切换编辑模块，从上至下分别是：

- 玩家与职业编辑：[玩家](../概念介绍/玩家__mhctmgi51lpo.md)[角色](../概念介绍/角色__mh3ecor1x5cm.md)[职业](../概念介绍/职业__mhodlcrpht3q.md)
- 单位状态编辑：[单位状态](../概念介绍/单位状态__mh6rh59iil2i.md)
- 技能编辑：[技能](../概念介绍/技能__mho81frl33im.md)
- 本地投射物编辑：[本地投射物](../概念介绍/本地投射物__mhciimiw86jg.md)
- 道具编辑：[道具](../概念介绍/道具__mhbgx0rspbqu.md)

# 二、新建与保存

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/c26f00a2-948b-494b-8827-30ea00d3c865.png)

通过资产栏的新建按钮可新建当前选中编辑模块对应内容。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/0f6d7301-77f4-4cee-9561-3e7a0f430426.png)

角色与职业编辑模块的内容修改后会自动保存，而单位状态、技能、本地投射物和道具的内容修改后需要手动进行保存。资产栏内对应内容出现黄色感叹号标识（如图所示）代表当前内容有未保存内容，可通过底部的保存按钮（如图所示）进行保存或另存为新内容。

# 三、切换性别

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/bb85cd1c-30fc-417d-afb1-c540f4fa8560.png)

底部的切换性别按钮可切换模特模型的性别。

# 四、镜头回正

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhexhcr1qjh2/9ebd6ae5-0025-4e94-9931-c7edb20c2290.png)

在战斗预设模块，右键场景空白处可呼出镜头回正选项，选择后镜头会恢复至初始状态
