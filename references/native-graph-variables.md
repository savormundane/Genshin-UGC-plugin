# 节点图变量声明、默认值与访问

能力名：native-graph-variables。scripts/native_graph_variables.py读取普通/复合图已校准的变量表及内建读写节点，检查声明、server VarBase默认值和静态访问类型，接入native inspect/audit、project索引、native diff和produce最终审计。仅使用包内读取器和Python标准库，原始输入只读。

## 使用与作用域

```text
python scripts/qianxing.py native inspect LEVEL.gil
python scripts/qianxing.py native audit LEVEL.gil
python scripts/qianxing.py project inspect LEVEL.gil
python scripts/qianxing.py project consumers LEVEL.gil --key level/graph_variable/ordinary/1073742600/Value
python scripts/qianxing.py native diff BEFORE.gil AFTER.gil
```

key中的图ID、图种类和变量名须替换为当前inspect结果。同名变量可以存在于不同图，同一图内不得重名；普通/复合图命名空间分开。节点图变量的生命周期和访问域跟随图，不能与实体自定义变量合并。复合图资源可读取不代表已经实现其运行调用模型。

native inspect返回graph_variables，包含graph、graph_kind、name、type_id、默认值摘要及字典子类型。graph_variable_accesses单独报告读写节点及其名称来源和解析状态。project保留相同对象信息；变量默认值的显式结构体引用以及静态读写消费者进入查询。native diff同时报告变量对象摘要、原始条目字节和消费者关系变化，不仅显示整个图变化。

## 原生合同

图正文重复字段6保存变量条目；条目2是名字、3是类型、4是VarBase默认值，字典7/8是键/值类型。空表标记不生成变量。非字典的7/8可保留旧写入器的6/6占位，不能当作真正字典子类型。

默认值与实体变量的typed-value格式不同。检查声明类型、VarBase的server ItemType和载体类一致；列表递归检查元素类型，字典核对声明、默认描述、每对键值的类型及载体。结构体/结构体列表默认值中显式保存的结构体身份必须存在，列表与元素的显式身份不得冲突。错误中保留图、变量和嵌套值路径。

原始全类型样本允许空结构体、空结构体列表和未写入非空载荷的空字典。不会为这些值猜选结构体，也不要求它们伪造实体变量描述符。非空结构体未显式保存身份时，本能力仅检查其已保存元素类型；不按成员形状猜测全局结构体，不声称身份索引完整。

未知类型、默认值方言和缺失默认值不能取得严格通过。标量数值范围/精度、全部载荷字段、图变量外部覆写、动态目标及运行时生命周期不由本检查认证。

## 读写访问与消费者

服务端获取节点图变量337和设置节点图变量323均使用数据输入0作为字符串名称；这不是编辑器元数据选择器。获取的值在输出0，设置的值在输入1。名称输入口按官方签名和原始校准补齐，不修改第三方目录。已知具体变体可解析没有显式存储的输出口类型。

| resolution/name_kind | 含义与检查 |
| --- | --- |
| declared/literal | 本图唯一声明。检查访问类型；两端均有显式结构体身份时检查相等；字典具体变体与声明的键/值类型必须一致。登记graph_variable_read或graph_variable_write关系 |
| default_if_absent/literal | 获取未声明名称。官方允许返回该类型默认值，不制造悬空声明引用；未证明运行时始终不存在 |
| undeclared_write/literal | 设置的名称没有静态声明。报告目标缺口，不推断平台动态创建语义或建立虚假引用 |
| unresolved/dynamic | 名称输入由数据线提供。即使输入保留字符串默认值，也不据此绑定变量；支持识别输入端、输出端或双端存储的连线 |
| unresolved/missing | 没有可解析的名称来源，不猜空字符串或跨图目标 |
| ambiguous/literal | 本图存在重复声明，最终审计失败 |

字符串端口携带非字符串常量会失败。静态访问的具体类型与声明不符，即使声明和默认值本身一致也失败。未知字典访问子类型不能取得严格通过。未显式保存的结构体身份仍不按成员形状推断。动态名称、未声明写入和缺失名称保留在访问记录与未覆盖范围，不认证完整引用索引或ID迁移安全；局部审计passed只代表已检查的合同。

依据为包内官方[查询节点](official/节点介绍/查询节点__mhwbqlrw655q.md)、[执行节点](official/节点介绍/执行节点__mhw66orrrfkm.md)和[节点图变量](official/附录/节点图变量__mhtshailzs7w.md)。名字只在当前普通/复合图命名空间解析，不跨图查找同名变量。

## 参数化使用与反例

第一套可包含整数、整数列表、带整数成员的结构体，以及整数键/整数列表值字典。第二套改用字符串、字符串列表、带字符串成员的结构体，以及字符串键/字符串列表值字典。使用各自图ID和结构体ID，同名变量跨图保留独立作用域。

两种配置都应通过读取、消费者查询和默认值变更差异。将声明改成布尔而保留原整数/字符串默认值、在列表中插入布尔载体、让字典键值类型不符、删除显式结构体依赖、复制同图变量名，均应失败。原始23种声明及空值表示另行核对，不修改校准文件。

两套真实Graph Code分别声明整数和字符串Value，经获取后设置同名变量；编译导出GIA、嵌入GIL并读取两个消费者。将声明与默认值一起改成布尔而保留原读写节点，应因访问类型冲突失败。另测结构体身份与字典键/值不符、名称常量载体不符、动态名连线方向和缺省读取。

## 制作与验证

produce在最终产物上执行同一检查，不需要额外变量检查开关。既有GIL可通过native.spec/plan迭代；必需审计失败不提交输出。portable携带原始基底及工具链，在原输入目录不可用时重新读取、检查和重建。

用最终文件回读变量名称、图作用域、默认值和引用。编辑器导入、节点执行和实际保存重进各有对应的验证步骤。
