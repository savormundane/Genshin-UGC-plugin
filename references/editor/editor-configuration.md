# 编辑器配置与资源绑定

客户端 Lua 挂载在客户端控件上。承载画布的「客户端控件容器」本身是服务器控件。核对脚本映射、模板索引、运行时控件 ID 和控件组所属实体。传送或重连后先检查旧引用是否有效，按需重建。

节点图绑定应包含图作用域、图 ID、宿主实体/元件、事件入口和运行阶段。GIA 可以包含尚未挂载的图。交付单个 GIL 时，回读挂载与关联定义。不要把玩家模板、实体实例、元件模板或客户端控件组互相替换。

音乐使用已配置的背景音乐索引及文档中的玩家目标；音效 ID、本地 MP3 和背景音乐索引不是同一种输入。原生匹配时限按文档接口或实际编辑器证据设置。局内计时不能代替匹配时限。阵营或个人结算先确认对象分组和合同，不从按钮文案推断退出范围。

具体配置名称和参数查 [官方索引](../platform/README.md)。导出或写回时，参见[节点图制作](../graph-code/node-graph-workflow.md) 与 [离线工具链](../graph-code/ayaya-offline-toolchain.md)。

新增协议及已有工程定义遵循[平台接口与工程合同](../workflows/implementation-policy.md)。
