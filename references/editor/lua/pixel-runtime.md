# 点阵帧动画接入

使用已生成的调色板和矩形数据接入帧动画。素材拟合和转换见[点阵像素指南](../../assets/pixel-import-guide.md)，接口见[客户端 API](../../platform/community/client-controls-api.md)。

按矩形最多的一帧建立控件池，分帧初始化。切帧时更新并复用已有图块，隐藏多余控件。移动角色时只移动父容器。不能每次切帧销毁重建控件。

矩形记录 {x,y,w,h,paletteIndex} 使用1起始调色板索引。相对锚点中心为 x+w/2-anchorX，朝向反转只对局部X取负；Y为 anchorY-y-h/2，二者乘显示比例。帧锚点不等于物理碰撞盒，角色状态来自当前项目。

不可交互图块关闭命中，分别处理可见性和激活状态。资源池失败时记录句柄和状态，避免重复分配；销毁级联行为以当前宿主实际验证为准。初始化完成才显示完整图。

验证数据边界、索引和覆盖，再检查模板、透明边缘、图层、触控、首次建池和切帧耗时。Lua模拟或图片预览不证明真实帧率。可用动作以原素材为准。

跨能力执行与交付由 [内部制作核心](../../workflows/produce-schema1.md) 的统一produce入口处理；兼容命令保留，当前核心和后端边界见该工作流。
