三个核心依据：奇匠学院官方文档、客户端控件API文档、点阵像素图处理与导入指南。API 签名与读写权限以 API 文档为准；编辑器/节点配置以官方文档为准；点阵转换以像素指南为核心流程参考。聊天经验与 GE/拟 L2D 资料只是补充，不覆盖这三项。核心来源有冲突时标出对象和版本差异，必要时做最小验证，不任意断定。


- 制作经验只保存可复用方法，不收录聊天原文、游戏素材、剧情、专用规则、完整脚本或存档。
- GE 工具手册与拟 L2D 知识库用于补充素材处理方法。原案例数据与测试数字不构成新项目的默认参数或平台限制。
- runtime/GE_IMG_Tool.exe 为原文件副本，本插件不包含工具源码或账户凭据；图元转换运行时无需把素材上传至云端。Python 拟 L2D 脚本需要环境依赖，未在本次验证实际转换流程。

## 来源冲突优先核对

当前 API 明确为 game.GetUICanvasSize()。写代码时按其精确拼写，不从旧示例猜别名。API 明确 active/visible/alive 只读，旧速查表把它们列在可读写/Tween 区域属于资料冲突；按正式字段权限和 SetActive/SetVisible 处理。

当前 API 已说明 Tween 的目标表以 Tweenable 字段名为键、目标值为值；旧知识库称格式缺失已不适用于这份 API。父级变换、旋转、裁剪、销毁级联、文本换行是否在当前设备生效，仍需宿主验证。

700/900 的像素经验预算、官方单组1000与单屏10000、图元性能建议3000、节点图报错3000是不同口径。必须标出计数对象、版本和验证来源，不把它们合并成一个限制。
