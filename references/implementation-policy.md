# 平台接口与工程合同

平台内置节点、Lua API 和原生资源 ID 以[官方资料](official-index.md)、内置目录和实际工程为依据。

- **已有定义**。从当前工程读取信号名称、方向、参数类型和顺序，以及图、模板、实体与存档的身份。改动合同前核对发送端、接收端和兼容范围。
- **项目自定义定义**。声明变量或信号的类型、作用域和生命周期。在对应注册表内分配标识，核对定义、挂载及所有调用方。
- **原生文件**。用对象键和基底摘要定位修改，另存产物并回读新增引用和受保护字段。未校准的结构按只读资料处理。[原生修改计划](native-changes.md)

编译、离线模拟、编辑器导入及宿主行为可以各自验证。[证据等级](validation.md)
