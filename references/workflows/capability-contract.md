# 跨领域任务交接

按[四个 Skill 的职责](skill-map.md)选择负责的领域。跨领域任务传递实际对象、版本和输入校验值，继续使用同一份工程定义。

| 边界 | 交接内容 |
| --- | --- |
| 原生工程 → Graph Code / Client Lua | 对象键、目标平台版本和模式、变量及信号约定 |
| Graph Code → GIL | 编译文件、信号与结构体声明、目标挂载及允许改动的字段 |
| Client Lua → GIL | 生成的 Lua、源码映射、确认的 API 和目标脚本映射 |
| Assets → Client Lua / GIL | 来源校验值、坐标、颜色、图层、控件预算和模板依赖 |
| 任一领域 → 诊断／交付 | 实际输入、产物校验值、检查结果与覆盖范围 |

依[平台接口与工程合同](implementation-policy.md)核对已有定义及新增内容。需要将阶段串到同一份关卡时，使用[组合制作](produce.md)。
