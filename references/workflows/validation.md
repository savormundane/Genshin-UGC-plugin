# 验证等级和交付记录

## 交付反馈

1. **产物与改动**。说明生成的文件和实际修改的对象、代码或配置。
2. **保存位置**。列出工具返回的输出位置，客户端支持时提供可点击入口。
3. **用法和检查**。写清导入、挂载、接入或继续编辑的方法。记录实际执行的检查及其结果。

## 验证等级

| 层级 | 可以依据的结果 |
| --- | --- |
| 文件与静态检查 | 输入校验值、容器结构、Lua 语法、受保护字段及已知引用 |
| 编译与写后读回校验 | 实际编译产物、端口及图、脚本或模板的实际挂载 |
| 离线模型 | 已执行的 Lua 或原生图路径、明确给定的传输与状态转换。模型的结算和重进只覆盖模型持久层。 |
| 软件预览 | 当前输入的画面、控件、布局和绘制断言 |
| 编辑器导入 | 指定产物已实际导入，核对映射、挂载和节点展开情况。保存后可重复读取核对。 |
| 游戏内运行 | 对应产物在实际客户端、设备和场景中的操作、显示、传输和持久化 |
| 玩家验收 | 创作者或试玩者沿目标路径观察手感、反馈与玩法目标 |

各条检查记录对应文件、SHA-256 校验值、操作、结果和覆盖范围。工具的 `passed`、`failed`、`not_checked`、`not_applicable` 按层解释。一项通过的结果只支持对应层和实际跑到的路径。验证真实存档重进时，使用同一玩家和同一发布关卡，从离场直到下一次首次读取。

用[能力与验证结果](validation-evidence.md)区分可用实现、离线回归和游戏内记录。历史报告留在原版本，新报告绑定本次实际输入与输出。

## 可复用验收项

- **节点与挂载**。从最终产物核对源输出类型、消费者端口、声明身份和保护字段。 [原生数据流](../graph-code/native-dataflow-validation.md)
- **界面与素材**。核对透明边缘、坐标、锚点、尺寸、顺序、颜色和实际控件数。用长名称、目标设备和重要输入动作检查命中。 [游玩检查](playability-workflow.md) · [素材检查](../assets/asset-inspection.md)
- **多人和持久化**。覆盖身份、过期和重复、非法输入、超时、掉线和恢复。把离线模型和同版本实测各自登记。 [联合模型](joint-simulation.md) · [存储](storage-authoring.md)
- **交付完整性**。新目录保存文件，从清单检查输入、产物和保护范围；携带交付重建再核对输入闭包和确定性产物。 [可迁移重建](portable-delivery.md)
