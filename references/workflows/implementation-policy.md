# 平台接口与工程合同

查平台内置节点和 Lua API 时注明官方资料与适用版本。资源目录、样本及社区整理的观察各自保留出处和适用范围。添加新的读写能力前，核对同一版本和模式的真实文件，缺少依据的结构只读取已校准的部分。 [平台资料与来源](../platform/README.md) · [维护流程](../../docs/contributing/platform-maintenance.md)

- **已有定义**。从当前工程读取信号名称、方向、参数类型和顺序，以及图、模板、实体与存档的身份。改动合同前核对发送端、接收端和兼容范围。
- **项目自定义定义**。声明变量或信号的类型、作用域和生命周期。在对应注册表内分配标识，核对定义、挂载及所有调用方。
- **原生文件**。用对象键和基底摘要定位修改，另存产物并回读新增引用和受保护字段。未校准的结构按只读资料处理。[原生修改计划](../gil/native-changes.md)
