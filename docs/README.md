## 第一次来

| 你处在哪一步 | 阅读入口 |
| --- | --- |
| 还没安装 | [安装、更新与卸载](installation.md)：选客户端，准备工程与输出目录 |

## 遇到问题

先看[安装指南](installation.md)里与当前操作对应的一节。无法解决时，直接[反馈问题](https://github.com/savormundane/Genshin-UGC-plugin/issues/new/choose)，附上插件版本、使用的客户端、操作步骤和报错；暂时不清楚的环境信息可以后补。
