# 第一次使用

先完成一次不需要游戏工程的节点查询，再选择一个你正在制作的任务。这个流程帮助你熟悉插件，不要求先读完技术资料。

[返回首页](../README.md) · [安装指南](installation.md) · [更多使用示例](examples.md)

## 1. 准备两个目录并安装

还没有工程也可以使用插件。先建一个空的输入目录，例如 `C:\Qianxing\project`，另选同级的 `C:\Qianxing\outputs` 保存生成文件。安装器所说的「项目目录」就是前者；之后把要处理的 `.gil`、`.lua` 或图片放进去即可。

项目和输出目录不能互相包含；不要把输出放进项目目录，也不要选择整个磁盘。按[安装指南](installation.md)选择客户端完成安装，然后打开新会话并启用 Genshin-UGC。

## 2. 查询一个真实节点

把下面的文字发送给助手：

> 请调用 Genshin-UGC 的 `nodes_lookup`，查询服务端的“启动定时器”节点。告诉我调用签名、数据输入端口类型，以及定时器序列怎么填写。

这次查询不需要 `.gil` 文件。工具从随包节点目录读取信息；你应当能在客户端的调用记录中看到 `nodes_lookup` 成功返回 `server` 范围的节点。

| 你会得到的信息 | 随包节点定义中的内容 |
| --- | --- |
| 调用签名 | `启动定时器(game, 目标实体, 定时器名称, 是否循环, 定时器序列)` |
| 数据输入 | 目标实体（实体）、定时器名称（字符串）、是否循环（布尔值）、定时器序列（浮点数列表） |
| 序列含义 | 从小到大排列的秒数时间点，最多 100 个；例如 `[1, 3, 5, 7]` 表示在对应时间点触发事件。 |

上述内容来自[随包节点定义](../vendor/ayaya/plugins/nodes/server/执行节点/启动定时器.py)。成功查询说明当前会话可以使用这项本地工具；接下来可以继续制作，不必反复重复这个步骤。

如果助手只给出解释、没有调用工具，提醒它实际调用 `nodes_lookup`。如果工具不可见，按[安装排障](installation.md#失败后续装)检查插件是否启用及安装目录是否保留完整。

## 3. 可选：做出一个不依赖私人工程的小素材

仓库提供了一份[完整蓝金徽章案例](../examples/hello-assets/README.md)：128×128 的输入 PNG，已经实际生成 9 个矩形、Lua 数据、预览和报告。可以先打开[生成预览](../examples/hello-assets/generated/preview.png)，再用自己的环境处理同一张图。

下载案例的 [input.png](../examples/hello-assets/input.png) 到项目目录中的 `hello-assets` 子目录，向能执行本地命令的助手发送：

> 用 Genshin-UGC 的 `assets generate` 处理项目目录里的 `hello-assets/input.png`。输出网格设为 128×128，目标为 rectangles，颜色上限为 4，矩形预算为 16。使用插件已配置的 Python，把结果保存到独立输出目录的新子目录，并给我 `preview.png`、实际矩形数和文件位置。

不需要游戏工程或私人图片。生成器写出 `asset.json`、`data.lua`、`preview.png`、`report.json`、`manifest.json`；案例还提供图形源与本次运行参数，便于自己修改颜色和尺寸。

本例使用 Linux 上的本地素材生成器制作，预览展示颜色和几何；在游戏界面使用仍需接入实际控件。本案例为当前源码新增，已发布的 4.1.0 ZIP 不含这些案例文件，但已有工具可以处理下载的输入图。只接入 MCP、不能执行本地命令的客户端，可以先完成上面的节点查询。

## 接下来做什么

| 你手上有什么 | 下一步 |
| --- | --- |
| 一个玩法想法 | 说明触发条件、玩家动作和期望结果，让助手先查询相关节点，再设计节点图。 |
| 已有 `.gil` | 从[工程检查](examples.md#工程检查)了解对象和挂载关系，再选择要改的部分。 |
| 已有界面脚本 | 按[客户端 Lua 示例](examples.md#编写客户端-lua)补充控件和信号背景。 |
| 一张 PNG | 按[图片转图元示例](examples.md#图片转图元)给出用途和矩形预算。 |

每次任务告诉助手：输入文件、目标千星奇域版本、想改变什么。插件可依据现有工具和资料完成查询、制作与局部检查；编辑器导入和游戏内表现见[运行要求与支持范围](compatibility.md)。
