# 运行要求与验证

完整插件适用于 **Windows x64**，使用 Python 3.11–3.12 和 Node.js 22 或更新版本。DeepSeek Harness 需要 Node.js 24.9 或更新版本。具体操作见[安装指南](../references/installation.md)。仅使用命令行工具时，见[独立运行环境](../references/runtime-environment.md)。

安装后，在所选客户端的新会话里确认插件可用，并做一次 API 查询。对生成的游戏文件，先看本地检查结果，再在实际使用的千星奇域版本中导入和试运行。

## 验证级别

1. **静态检查**：检查语法、文件结构和配置规则。
2. **离线工具**：运行本地工具、Lua 或节点模型，或生成软件预览。
3. **编辑器导入**：在千星奇域编辑器中打开目标文件并检查内容。
4. **游戏宿主**：在游戏环境中运行并检查实际行为。
5. **使用者验收**：体验玩法并确认是否满足制作目标。

提交验证报告时，请写清平台和客户端版本、用例、实际完成的检查和已知限制。[详细验证说明](../references/validation.md)
