# 跟做两个创作者任务

两个教程用 [v1.0.0 首发源码](https://github.com/savormundane/miliastra-wonderland-plugin/tree/v1.0.0) 和本机 Codex 实跑。样例输入是为教程制作的公开素材和合成关卡。每篇都给出实际提示、调用、输出和后续用法。

- [PNG 转图元](png/README.md)。用 20 个控件的预算比较预览，再生成选中方案的数据和 Lua。
- [局部修改 GIL](gil/README.md)。定位变量和继承关系，审阅计划后另存，再回读改动和差异。

先按 [安装指南](../../docs/installation.md) 准备本机客户端和运行环境。复现时将样例输入复制到可读的工程目录，在启用插件的对话中打开该目录。写入使用独立的新输出目录，按需参考[工程和输出绑定](../../docs/runtime-environment.md#连接-mcp-或切换工程)。

预览图属于离线软件预览。GIL 示例核验了文件结构、改动和差异。千星奇域编辑器导入及游戏内运行待实测。
