# 创作者教程

涉及关卡或素材时，把样例复制到已授权的工程目录，再按[工程和输出绑定](../../docs/runtime-environment.md#连接-mcp-或切换工程)选择输出位置。

| 想做什么 | 准备什么 | 能看到什么 |
| --- | --- | --- |
| [查询节点](../../docs/installation.md#首次工具验证) | 启用本地 MCP | 「创建实体」的输入、输出与来源 |
| [从零做原型](../../references/workflows/staged-production.md) | 空工程目录和一句玩法设想 | 初版源码、产物和适用的检查 |
| [只读查找关卡对象](gil/README.md#只读查找关卡对象) | 复制公开的 `entrance.gil` 并授权读取 | 模板、继承实例及引用 |
| [审阅并另存 GIL](gil/README.md#审阅并另存) | 同一份 `entrance.gil`、独立输出位置 | 审阅计划、另存关卡与前后差异 |
| [排查 Lua 语法错误](lua/README.md) | 复制两行公开示例并授权读取 | 缺失的 `end`、修复代码和编译复检 |
| [PNG 转图元并放上界面](png/README.md) | 公开样图、控件预算、独立输出位置 | 候选预览、图元数据与可挂载的 Lua 样例 |

样例使用公开素材与合成关卡。各篇分别标明资料查询、文件回读、Lua 编译或软件预览的验证范围。编辑器导入和游戏内运行按具体产物验收。
