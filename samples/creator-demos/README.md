# 五个创作者任务

先在 Windows 上安装并启用插件，打开支持本机工具的对话。查询节点无需工程文件。涉及文件时，复制样例输入到已授权的工程目录。生成文件时，在独立输出根下选择一个新目录。 [安装指南](../../docs/installation.md) · [工程和输出绑定](../../docs/runtime-environment.md#连接-mcp-或切换工程)

| 想做什么 | 准备什么 | 能看到什么 |
| --- | --- | --- |
| [查询节点](../../README.md#查询第一个节点) | 启用本地 MCP | 「创建实体」的输入、输出与来源 |
| [只读查找关卡对象](gil/README.md#只读查找关卡对象) | 复制公开的 `entrance.gil` 并授权读取 | 模板、继承实例及引用 |
| [审阅并另存 GIL](gil/README.md#审阅并另存) | 同一份 `entrance.gil`、独立输出位置 | 审阅计划、另存关卡与前后差异 |
| [排查 Lua 语法错误](lua/README.md) | 复制两行公开示例并授权读取 | 缺失的 `end`、修复代码和编译复检 |
| [PNG 转图元](png/README.md) | 公开样图、控件预算、独立输出位置 | 候选预览、实际控件数、图元 JSON 和 Lua |

样例使用公开素材与合成关卡。各篇分别标明资料查询、文件回读、Lua 编译或软件预览的验证范围。编辑器导入和游戏内运行按具体产物验收。
