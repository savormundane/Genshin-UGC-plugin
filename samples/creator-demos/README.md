# 创作者教程

启用插件后，可先查询节点。跟做关卡或素材任务时，把样例复制到已授权的工程，并按需选择输出位置。 [安装](../../docs/installation.md) · [工程绑定](../../docs/runtime-environment.md#连接-mcp-或切换工程)

| 想做什么 | 准备什么 | 能看到什么 |
| --- | --- | --- |
| [查询节点](../../docs/installation.md#首次工具验证) | 启用本地 MCP | 「创建实体」的输入、输出与来源 |
| [只读查找关卡对象](gil/README.md#只读查找关卡对象) | 复制公开的 `entrance.gil` 并授权读取 | 模板、继承实例及引用 |
| [审阅并另存 GIL](gil/README.md#审阅并另存) | 同一份 `entrance.gil` 和独立的输出目录 | 修改计划、另存的关卡和前后差异 |
| [排查 Lua 语法错误](lua/README.md) | 复制两行公开示例并授权读取 | 缺失的 `end`、修复后的代码和再次编译的结果 |
| [PNG 转图元并接入界面](png/README.md) | 公开样图、控件预算和独立的输出目录 | 候选方案的预览、图元数据和可挂载的 Lua 样例 |
